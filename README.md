# 📝 To-Do List App

A clean, minimal to-do list app built with vanilla JavaScript, HTML, and CSS. Add, complete, and delete tasks — with everything saved automatically in your browser using `localStorage`.

🔗 **Live Demo:** [https://rohit73848.github.io/todo-web-app/](https://rohit73848.github.io/todo-web-app/)

## Features

- ✅ Add new tasks (via button click or Enter key)
- ✅ Mark tasks as complete/incomplete with a toggle
- ✅ Delete tasks
- ✅ Task statistics — total, completed, and remaining count
- ✅ Empty state message when no tasks exist
- ✅ Data persists across page reloads using `localStorage`
- ✅ Input validation (prevents adding empty/blank tasks)
- ✅ Responsive design for mobile

## Built With

- **HTML5** — semantic structure
- **CSS3** — custom properties (variables), Flexbox, responsive layout
- **JavaScript (Vanilla)** — DOM manipulation, event delegation, array methods (`map`, `filter`, `find`), `localStorage` API

## Key Concepts Practiced

- Array-based state management (single source of truth pattern)
- Event delegation for dynamically created elements
- Data-driven rendering (UI updates automatically from data changes)
- Working with `localStorage` for data persistence

## How to Run Locally

1. Clone the repository:
```bash
   git clone https://github.com/rohit73848/todo-web-app.git
```
2. Open `index.html` in your browser — no build steps or dependencies required.
